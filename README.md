# 猴子也能懂的 AI Road Map（網頁版電子書）

2026 新手完全指南，從聊天機器人一路學到 AI 代理人。手機優先的單欄卡片式閱讀版。

- 線上閱讀：`ai-roadmap-2026.html`（`index.html` 會自動轉過去）
- PDF 收藏版：頁面上的 PDF 按鈕
- 免費公開課《為什麼我鼓勵你創業》：頁面結尾的入口

## 更新方式

正文來源是 Obsidian 保管庫裡的 `猴子也能懂的AI Road Map-電子書正文.md`。
改完內容後執行 `build_web.py` 重新產出 HTML，覆蓋本專案的檔案再推上來即可。

本專案的 `images/` 是網頁用的壓縮版（WebP，最長邊 1400px），
原始高解析圖仍保留在保管庫中，供 PDF 排版使用。
